# Jove Tristan Pelones — E-Portfolio

A responsive multi-page student portfolio built with React, Vite, React Router, and Tailwind CSS.

## Pages
- Home
- About
- Projects
- Resume / CV
- Contact

## Run locally
1. Install Node.js (LTS).
2. Open this project folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Build and deploy to Vercel
1. Push the project folder to a GitHub repository.
2. Sign in to Vercel and import that repository.
3. Vercel should detect Vite automatically. Build command: `npm run build`; output directory: `dist`.
4. Deploy, then open the public URL and test every page and link.

## Before submitting
- Confirm the personal details and wording are accurate.
- Replace project descriptions with actual screenshots or repository links if you have them.
- Review the generated CV PDF before using it professionally.
- The contact form validates fields and opens the visitor's email application using a `mailto:` link. It does not store or send messages from a backend.
- This is the source project; it is not yet deployed to a public Vercel URL.
